sdc-xsd-models
==============

Python classes from xsd schemas related to sdc.

Included schemas are

* `dpws <https://docs.oasis-open.org/ws-dd/ns/dpws/2009/01>`_
* `ws-eventing <https://schemas.xmlsoap.org/ws/2004/08/eventing/>`_
* `ExtensionPoint <https://standards.ieee.org/wp-content/uploads/import/download/11073-10207-2017_downloads.zip>`_
* `WS-MetadataExchange <https://schemas.xmlsoap.org/ws/2004/09/mex/>`_
* `BICEPS_MessageModel <https://standards.ieee.org/wp-content/uploads/import/download/11073-10207-2017_downloads.zip>`_
* `BICEPS_ParticipantModel <https://standards.ieee.org/wp-content/uploads/import/download/11073-10207-2017_downloads.zip>`_
* `soap-envelope <https://www.w3.org/2003/05/soap-envelope/>`_
* `WS-Addressing <https://www.w3.org/2005/08/addressing/>`_
* `WS-Discovery <https://docs.oasis-open.org/ws-dd/discovery/1.1/os/wsdd-discovery-1.1-spec-os.html>`_
* `wsdl <https://schemas.xmlsoap.org/wsdl/>`_
* `xml <https://www.w3.org/XML/1998/namespace>`_
