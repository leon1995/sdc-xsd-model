sdc-xsd-models
==============

Generated python classes from xsd schemas related to sdc.

Included schemas are
- [dpws](https://docs.oasis-open.org/ws-dd/ns/dpws/2009/01)
- [ws-eventing](https://schemas.xmlsoap.org/ws/2004/08/eventing/)
- [ExtensionPoint](https://standards.ieee.org/wp-content/uploads/import/download/11073-10207-2017_downloads.zip)
- [WS-MetadataExchange](https://schemas.xmlsoap.org/ws/2004/09/mex/)
- [BICEPS_MessageModel](https://standards.ieee.org/wp-content/uploads/import/download/11073-10207-2017_downloads.zip)
- [BICEPS_ParticipantModel](https://standards.ieee.org/wp-content/uploads/import/download/11073-10207-2017_downloads.zip)
- [soap-envelope](https://www.w3.org/2003/05/soap-envelope/)
- [WS-Addressing](https://www.w3.org/2005/08/addressing/)
- [WS-Discovery](https://docs.oasis-open.org/ws-dd/discovery/1.1/os/wsdd-discovery-1.1-spec-os.html)
- [wsdl](https://schemas.xmlsoap.org/wsdl/)
- [xml](https://www.w3.org/XML/1998/namespace)
